# Stages 2-3: Script Format and Series Bible

## Script format (Stage 2)
Write scripts as **compressed beat lists**, not full screenplay prose — each beat is a short description of what's visible/said, numbered, 8-10 beats for a short-form episode (60-180 seconds). This format translates directly into picture draft prompts later; prose has to be re-translated, which wastes effort.

For a full-detail episode script (when the user wants production-ready, not just planning-level), expand each beat with:
- **ACTION:** what's visible
- **DIALOGUE:** character lines (keep short — one sentence per beat is normal for short-form)
- **CAMERA NOTE:** one instruction (close-up, wide, push-in) — not a paragraph of cinematography

For a full season (10-35 episodes), write **Episode 1 at full production detail**, and the remaining episodes as a **logline-level season outline** (1-3 sentences per episode, grouped into acts) unless the user explicitly asks for every episode fully scripted. Fully scripting a long season in one pass is usually more than needed for planning and risks errors from doing too much at once.

## Series Bible template (Stage 3)
One document per show, written once, referenced before every episode. Sections:

- **Genre/Trope:** the closest comparable reference points; what this show is and isn't.
- **Tone:** how restrained vs. melodramatic, how much humor vs. stakes.
- **World Rules:** setting (use invented place names, not real specific locations — see fictionalization note below), any invented organizations/companies involved in the plot, language/dialogue conventions.
- **Leads:** for each major character — core want, core flaw, relationship to other leads. Give antagonists genuine motivation, not cartoonish villainy, unless the tone specifically calls for a over-the-top villain.
- **Season Arc:** 4-5 major turns across the whole season, not per-episode beats.
- **Visual Style:** color palette (often split by emotional/location register — e.g., warm for one world, cool for another), a recurring visual motif, camera language conventions.
- **Episode Formula:** the beat structure every episode follows (e.g., hook → rising tension → emotional turn → cliffhanger).

## Fictionalization — do this by default for any show touching real-world-adjacent themes
If the show's premise echoes a real scandal, real political situation, real company practice, or any sensitive real-world pattern:
- Invent all place names, company names, and official titles — never use a real, identifiable location name (even a real street name in passing).
- Never name or thinly veil real public figures, politicians, or companies.
- Keep antagonists and institutions fictional and specific to the story's world, not generalized claims about real governments/companies.
- This isn't just a safety consideration — it also protects monetization eligibility on most platforms, which typically require "no policy violations" as a standing eligibility condition, not just a one-time check.

If a real-sounding name slips into later scripts or prompts (happens easily — a real street, a real brand), catch and replace it as soon as noticed, across every file it appears in, not just the current one.
